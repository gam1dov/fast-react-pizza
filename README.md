# Fast React Pizza - Food Delivery App

A modern pizza ordering application built with React, featuring real-time order tracking, geolocation, and state management with Redux.

## 🚀 Live Demo

**Application:** https://fast-react-pizza-sable-beta.vercel.app/


## 🛠️ Tech Stack

- **Framework:** React 18
- **Routing:** React Router v6
- **Styling:** TailwindCSS
- **State Management:** Redux Toolkit (with Thunks)
- **Build Tool:** Vite
- **API:** External pizza API integration
- **Features:** Geolocation API

## ✨ Features

### 🍕 Menu & Ordering
- 📋 **Interactive Menu** - Browse pizza selection with images, ingredients, and prices
- 🔍 **Pizza Details** - View detailed information about each pizza
- 🛒 **Shopping Cart** - Add/remove pizzas, adjust quantities, real-time price calculation
- ⏱️ **Estimated Delivery Time** - Dynamic calculation based on user location

### 📍 Location & User
- 🌍 **Geolocation Integration** - Auto-detect user's location for delivery estimation
- 📝 **Order Form** - Collect delivery address and phone number
- 👤 **User State Management** - Track user name and order history
- 🔔 **Order Status** - Real-time order tracking with status updates

### 🎨 UI/UX
- 📱 **Responsive Design** - Mobile-first approach with TailwindCSS
- 🎯 **React Router** - Seamless navigation between menu, cart, and order pages
- ⚡ **Fast Performance** - Optimized with Vite build tool
- 🎨 **Modern Styling** - Clean, intuitive interface with Tailwind utility classes
